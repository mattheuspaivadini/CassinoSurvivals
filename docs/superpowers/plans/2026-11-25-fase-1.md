# Fase 1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar a Fase 1 do PDF: arena do Blockout 1 com 6 portas, horda finita de 25 que libera a saída, e IA de inimigos que contorna obstáculos.

**Architecture:** Lógica pura e testável (`ArenaGrid`, `FlowField`, `HordePlan`) em `scripts/Level/`, verificada pelo `SelfCheck`. Nós finos por cima (`Arena`, `SpawnDoor`, `HordeDirector`, `ExitDoor`, `OffscreenPointers`). `EnemySpawner` vira registro (com `AutoSpawn` desligado na Fase 1). A cena `scenes/levels/Fase1.tscn` é gerada por um script Python fora do repo e vira a main scene.

**Tech Stack:** Godot 4.7.2 .NET, C# (.NET 10), Python 3 + Pillow (só para gerar recortes e a cena).

**Spec:** `docs/superpowers/specs/2026-11-25-fase-1-design.md`

### Task 1: ArenaGrid + FlowField (lógica pura)

**Files:**
- Create: `scripts/Level/ArenaGrid.cs`, `scripts/Level/FlowField.cs`
- Modify: `scripts/SelfCheck.cs`

**Interfaces:**

- Produces: `FlowField(ArenaGrid)`, `Compute(Vector2I target)`, `DistanceAt(Vector2I)`, `bool NextCell(Vector2I from, out Vector2I next)`, `Vector2 Direction(Vector2 worldPos)`.

- [ ] Step 1: teste no `SelfCheck` — grade 10×5 (célula 1px), parede na coluna x=5 de y=0 a 3 (vão em y=4). Alvo (9,0). Seguindo `NextCell` a partir de (0,0): nunca entra em célula bloqueada e chega ao alvo em < 100 passos. `LineClear((0.5,0.5),(9.5,0.5))` é false; `LineClear((0.5,4.5),(9.5,4.5))` é true.
- [ ] Step 2: build falha (tipos inexistentes).
- [ ] Step 3: implementar. Grade marca célula bloqueada se intersecta o retângulo sólido inflado. BFS de 8 vizinhos sem cortar quina (diagonal só se as duas ortogonais estão livres). O alvo é semente mesmo se estiver bloqueado (o jogador pode encostar num pilar). `NextCell` escolhe o vizinho de menor distância; `Direction` devolve o vetor até o centro dele (ou `Vector2.Zero`).
- [ ] Step 4: `dotnet build` + selfcheck OK.
- [ ] Step 5: commit `feat(level): grade da arena e flow field`.

- [ ] Step 1: teste — `Build(25, 60, 6, 2, {2,5}, 2.5, rng seed 7)`: 25 entradas, 2 elites (uma no primeiro quarto, outra no último), tempos crescentes dentro de [0, 60], nenhuma porta 2/5 antes de 2,5s.
